# MasteryPath AI – From Confusion to Mastery

An AI-powered personalized adaptive learning platform that helps students understand concepts, identify knowledge gaps, and achieve mastery through intelligent learning and assessment.

## Overview

MasteryPath AI is designed to make learning more personalized and effective. Instead of providing the same learning experience to every student, it adapts the learning process according to individual knowledge levels and understanding.

Students can upload study materials, learn through structured modules, evaluate their understanding, and receive additional explanations for concepts they find difficult.

## Key Features

- **Personalized Learning:** Adapts learning to the student's knowledge level and learning goals.
- **PDF-Based Learning:** Uses uploaded study materials as learning resources.
- **Module-Based Teaching:** Divides learning materials into manageable modules.
- **Knowledge Assessment:** Evaluates student understanding through assessments.
- **Weak Concept Detection:** Identifies concepts that require additional attention.
- **Adaptive Reteaching:** Revisits difficult concepts to improve understanding.
- **Mastery-Based Progression:** Supports progression when the student demonstrates sufficient understanding.

## How It Works

1. Enter a subject, learning goal, and knowledge level.
2. Upload a study PDF.
3. The system extracts and organizes the material into modules.
4. Learn one module at a time.
5. Complete assessments to evaluate understanding.
6. Identify weak concepts and revisit them.
7. Continue learning as understanding improves.

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/seJal-web/MasteryPath-AI.git
```

2. Navigate into the project:

```bash
cd MasteryPath-AI
```

3. Create and activate a virtual environment.

4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Configure the required API credentials using a local `.env` file. Never upload real credentials to GitHub.

6. Run the application using the appropriate command for your project.
